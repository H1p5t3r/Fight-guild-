# Preliminary move data

Generated by `python scripts/generate-combat-data.py`. Edit `godot/data/starter_moves.json` for defaults, or use the in-game Move editor for local tuning. These are first-pass values, not final balance.

All startup is at least **5 frames** at 60 Hz. Active frame 1 is the startup-numbered tick. Block advantage below assumes first-active-frame contact: blockstun − (active − 1 + recovery). No invulnerability is implied by reversal eligibility.

Moves without dedicated signature art reuse the button strike rectangle. Fillet/Shark signatures use their own body/strike geometry; hooks use eight narrow moving rectangles along the spear, with a harmless rope. See [signature behavior and inputs](signature-moves.md). Weapons can deal damage but never extend hurtboxes. 2D is a universal low sweep; 4P+K and 6P+K are universal ground throws. These new slots reuse existing button art pending dedicated animation. Ground/air strike push is a distance budget in pixels, travelled over six action ticks and stopped by wall contact; block push is contact displacement. Launch is upward pixels per tick. KD: 0 none, 1 soft, 2 hard; down/wake durations are ticks.
