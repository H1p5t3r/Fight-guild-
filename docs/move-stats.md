# Preliminary move data

Generated by `python scripts/generate-combat-data.py`. Edit `godot/data/starter_moves.json` for defaults, or use the in-game Move editor for local tuning. These are first-pass values, not final balance.

All startup is at least **5 frames** at 60 Hz. Active frame 1 is the startup-numbered tick. Block advantage below assumes first-active-frame contact: blockstun − (active − 1 + recovery). No invulnerability is implied by reversal eligibility.

Hitboxes follow the currently shared button art; crouching, command, special and aerial slots reuse that button’s strike rectangle until their own animations exist. Weapons can deal damage but never extend hurtboxes. All attacks currently use mid guard level; universal overhead/anti-air/throw design remains deferred.
