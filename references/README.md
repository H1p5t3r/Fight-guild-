# Miniature reference sources

Downloaded reference images are preserved in `miniatures/`. Source pages are listed below and in `sources.json`. They are reference material, not original project artwork.

Original Season II packaging provides a clearer view than the current front-facing sculpt image. | [Noble Knight: original Fillet miniature](https://www.nobleknight.com/P/2147623700/Fillet), [Steamforged: The Scarlet Circle](https://steamforged.com/products/guild-ball-the-butchers-guild-the-scarlet-circle) |

Search thumbnails sometimes mislabeled other characters as Fillet or Shark. The saved named product images were opened directly to inspect them. These are stylized concept adaptations; final production drawings should still be checked against the references, especially weapon proportions and secondary details.
