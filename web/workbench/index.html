WORK ANYWHERE

Your moves. Your browser.

  1. Choose a fighter and move. Tune numbers, routes or hitbox dimensions.
  2. Use Art brief to describe poses and effects, and attach pose-reference photos with captions.
  3. Download JSON to keep a backup or move between PCs.
  4. At home, import it through the Godot move editor, or send the JSON back here for the next sprite pass.

Drafts are saved in this browser when storage is available. They do not sync between devices, and clearing browser data removes the local draft.

The page works offline without installing anything. It makes no network requests. Preview playback holds existing poses; it does not run a match or regenerate artwork.

Startup cannot go below 5 frames. Positions are in game pixels; speed is pixels per frame. Existing global rules and the other fighters’ data are preserved when you edit a move.

Pose photos and notes travel in the workshop JSON. Keep that file: Godot exports gameplay values only.
